ATUALIZAÇÃO PERIÓDICA

Quando os tickets aparecem?

Uma rotina do GitHub verifica os workflows a cada 30 minutos e publica uma nova captura quando os dados mudam.

  1. O ticket precisa estar registrado na branch acompanhada de seu repositório: AutoOs/feature, AutoBO/main ou AutoPlatform/main.
  2. A rotina relê os três arquivos e publica o novo snapshot após detectar mudança.
  3. Recarregue esta página para ver os dados publicados. A fila do GitHub Pages pode acrescentar alguns minutos.

iO plano Fiscal PROD é editorial: mudanças nos tickets atualizam o DAG e os estados capturados, mas a recomendação de prioridade precisa de revisão humana.
